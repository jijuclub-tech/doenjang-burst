# 된장 폭발 대전

휴대폰 세로 대전 게임 제작 프로젝트. 엔진은 Phaser 3 + Vite. 진짜 3D가 아니라 하늘 섬 위의 가짜 입체 칸이다.

## 지금 있는 것

- 시작 화면에서 작은 마당, 큰 마당, 마을 섬을 고른다.
- 고른 맵의 배경 그림이 미리보기에 바뀐다.
- 마을 섬은 집마다 참가자가 나온다.
- 이동은 옆 칸만 누른다.
- 글씨는 18px 아래를 쓰지 않는다. 화면 확대 금지는 넣지 않는다.

배경 파일은 `bg/small.jpg`, `bg/large.jpg`, `bg/village.jpg`.

바로 보려면 `start.html`을 연다. Phaser 쪽은 `npm install` 다음 `npm run dev`.

## 규칙

- 항아리는 된장 또는 똥 중 하나만 담는다.
- 된장 명중은 배부름. 한계면 그 집 화장실만 넘친다.
- 구더기는 바닥 똥만 먹고, 닿으면 감점. 청소가 끝나면 화장실이 복구되고 잠시 된장 봉인.
- 똥 명중은 경직이고 바닥에 남는다. 된장이 그 똥에 맞으면 콩이 열린다.

이 저장소가 게임 제작 본선이다. 지주 PWA 호박 게임 글자 수정과는 별도다.
